# Contributing

Issues and pull requests are welcome. This is a small project, so a short
issue describing what you want to change is the best place to start.

## Setting up

Follow the quick start in the [README](README.md): a Python 3.10 to 3.12
virtual environment, the `references/auto_avsr` checkout, and the checkpoint if
you need real transcripts. Most work on preprocessing, streaming and the API
does not need the checkpoint.

## Before opening a pull request

There is no CI yet, so please run these locally:

```bash
python -m pytest                 # all 158 tests should pass
ruff check .                     # Python lint, settings in pyproject.toml
cd apps/web && npx eslint . && npm run build
```

If you change anything in `ml/preprocessing` or the model adapter, also run
the evaluation in [docs/evaluation.md](docs/evaluation.md) and include the
before and after WER in the pull request. Small changes there can make the
model quietly worse without any error.

## Ground rules

- **No real faces in the repo.** Test clips are generated by the scripts in
  `scripts/`. Do not commit videos, LRS3 samples or weights; `.gitignore`
  already excludes `data/`, `checkpoints/` and `references/`.
- **Honest numbers only.** Any accuracy or speed figure in the docs should come
  from a script in this repo, with the sample size next to it.
- **Never hide a failure.** If the pipeline cannot produce a transcript, return
  an `error`, not a guess.
- **Keep the layers apart.** The web app should not know which model is
  running, and model code should not import anything from `services/` or
  `apps/`.
